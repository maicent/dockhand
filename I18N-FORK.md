# i18n fork maintenance (zh-CN)

This fork tracks upstream `Finsys/dockhand` and adds a complete Simplified
Chinese UI on top. Upstream has its own official i18n (Paraglide, hand-named
keys, `src/lib/i18n/messages/`, see Finsys/dockhand#494) which we contribute
zh-CN translations to via per-area PRs. This branch exists because upstream
coverage is incremental; here the whole UI is Chinese today.

## Branch layers (bottom → top)

1. `add paraglide-js i18n framework...` — hand-written. Paraglide setup,
   cookie + browser-language strategy, `%lang%` replacement in hooks,
   Settings > General language selector. Rebased by hand on upstream updates.
2. `add i18n-extract codemod...` — hand-written tooling:
   - `scripts/i18n-extract.ts` — AST codemod that rewrites hardcoded UI text
     into `m.<slug>()` calls. Deterministic keys: unchanged text ⇒ unchanged
     key, so the extraction layer is disposable and regenerable.
   - `scripts/i18n-map.ts` — maps upstream's per-area `en.json` (hand-named
     keys, ICU plural arrays) onto our zh dictionary by English source text.
     Fallbacks: case-insensitive, placeholder-name normalization (our
     `{arg1}` vs upstream's `{name}`). Hand translations live in
     `scripts/i18n-map-overrides.zh-CN.json`.
   - `src/lib/i18n.ts` — `orEmpty` display helper.
3. `extract hardcoded UI strings...` — 100% generated by
   `npm run i18n:extract`. Never edit by hand; drop and regenerate.
4. `add zh-CN translations` — the dictionary (`src/messages/zh-CN.json`).
   Only new keys reported by the extractor need translation.

## On every upstream release

```sh
git fetch upstream
git checkout -b i18n-next upstream/main
git cherry-pick <framework> <codemod> <dict>   # layers 1, 2, 4
npm run i18n:extract                            # regenerates layer 3, lists new keys
# translate new keys in src/messages/zh-CN.json, commit, force-push i18n
```

Local dev requires Node 22 (better-sqlite3 crashes on Node 24); production
Docker builds use Bun and are unaffected. `svelte-check` has an upstream
baseline of 824 errors — compare multisets, not counts, and ignore
`LocalizedString` wording changes.

## Upstream contribution cadence

After each upstream area PR merges (containers ✓, stacks, images, settings…):
map its `en.json` with `scripts/i18n-map.ts`, hand-fill the gaps into the
overrides file, run `bun test tests/i18n-messages.test.ts`, and open a
translation-only PR adding only new keys to upstream's
`src/lib/i18n/messages/zh-CN.json`.
